# ☕ Java Basic Commands

> A study repository created to practice the **fundamentals of the Java language**, bringing together practical examples, basic commands, and reference materials.

The content is organized by topics, with **`.java`** files containing practical examples and **`.md`** files containing support materials in Portuguese and English.

---

## About the Project

This repository brings together studies and examples of the main fundamentals used in the early stages of Java development.

The project is organized in a simple way and separated by topics, making it easier to navigate through the code and find specific content.

### Available Content

| Content              | Description                                      |
| -------------------- | ------------------------------------------------ |
| **Variables**        | Declaration, storage, and manipulation of values |
| **Input and Output** | Data input and information output                |
| **Operators**        | Mathematical, relational, and logical operations |
| **Conditionals**     | Structures used to make decisions                |
| **Loops**            | Structures used to execute commands repeatedly   |
| **Methods**          | Code organization and reuse                      |

# Requirements

To run the Java examples, you need to have a **JDK (Java Development Kit)** installed.

Check the installation with:

```bash
java -version
```

And:

```bash
javac -version
```

---

# Running the Examples

The `.java` files can be run using an IDE or through the terminal.

### Terminal

Compile the file:

```bash
javac FileName.java
```

Run it:

```bash
java FileName
```

Example:

```bash
javac VariaveisJava.java
java VariaveisJava
```

### IDE

You can also open the project in a Java-compatible IDE and run the classes that contain the following method:

```java
public static void main(String[] args)
```
